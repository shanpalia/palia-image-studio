# Palia Resizer Studio — By PaliaAPK HUB

GitHub Pages static site. Root `index.html` is the branded homepage.

## Tools
- **Image Resizer & Compressor** (`resizer.html`): browser canvas resize, aspect-ratio control, rotate/flip, JPG/PNG/WebP export and target-size compression attempts.
- **Background Remover** (`background-remover.html`): existing browser-based background-removal workflow.
- **Image Enhancer** (`enhance.html`): existing photo editor workflow.

## Deploy
GitHub repository Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## No fake data
Homepage contains no invented user counters, ratings, download counts, or pretend AI results. AI is not claimed active unless a real model is connected.

## Quality
PNG export is lossless for rendered pixel data. JPG/WebP compression is lossy. Enlarging a low-resolution image cannot recover missing details. Browser canvas export may not preserve EXIF metadata.
